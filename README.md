# Applicant Handling & Recruitment Pipeline

A multi-step recruitment automation built with Zapier.

The workflow automates the initial handling of job applications — from form submission and filtering to applicant tracking, email confirmation, internal notification and screening task creation.

## Workflow

Google Forms → Filter by Zapier → Google Sheets → Gmail → Slack → Trello

## Workflow Steps

1. **Google Forms** — Captures applicant information.
2. **Filter by Zapier** — Only applications for the selected position continue.
3. **Google Sheets** — Stores qualifying applications in a structured applicant tracker.
4. **Gmail** — Sends an automated confirmation email to the applicant.
5. **Slack** — Notifies the HR team of the new application.
6. **Trello** — Creates a screening task with the relevant applicant information.

## Data Flow

Applicant data is mapped between the connected applications, allowing the same information to flow through the recruitment process without manual data entry.
